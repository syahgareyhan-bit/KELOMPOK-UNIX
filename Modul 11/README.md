# MotoMind

MotoMind merupakan proyek pengelolaan data layanan bengkel motor yang dibuat menggunakan **MongoDB**. Proyek ini bertujuan untuk menyimpan dan mengelola data bengkel, pelanggan, kendaraan, jenis servis, transaksi servis, serta katalog layanan dalam bentuk database NoSQL.

Database MotoMind terdiri dari beberapa collection yang saling berkaitan untuk mendukung pengelolaan informasi pelanggan, kendaraan, dan riwayat servis. Proyek ini juga menerapkan fitur MongoDB seperti `insertMany()`, query, aggregation, indexing, dan schema validation.

**Teknologi yang digunakan:**
- MongoDB
- MongoDB Shell (`mongosh`)
